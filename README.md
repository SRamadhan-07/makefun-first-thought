A Python program — standard library only, no network — that writes exactly one word to /output/entry.txt: "Petrichor", the first thought — the smell of rain on dry earth. The word is 9 characters, inside the competition's gate of exactly one word of 1 to 24 characters, and the file is byte-identical on every run.

## Run it

```sh
python3 main.py
```
